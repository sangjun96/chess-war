AI 활용

AI는
두 가지 작업에
활용했습니다.

Chess War 제작 과정에서 AI를 보조 도구로 활용했습니다. 게임의 핵심 규칙은 직접 설계하고, 구현과 사운드 제작처럼 반복적인 작업을 빠르게 다듬는 데 집중했습니다.

생성된 결과물은 실제 게임에 적용하기 전에 실행과 플레이 테스트를 거쳐 필요한 부분만 반영했습니다.

사용 도구
ChatGPT · ElevenLabs
활용 영역
코드 설계와 구현 · 효과음 생성
검수 방식
직접 실행 · 반복 플레이 테스트
01 개발

ChatGPT

코드 개발 지원

게임 규칙을 코드로 옮기고, 기능을 작은 단위로 나누어 구현하는 과정에서 활용했습니다.

  • 기물의 이동·공격 규칙과 체력 시스템의 구조를 정리했습니다.
  • AI 상대의 행동, 입력 처리, 전투 효과처럼 반복되는 기능의 구현 방향을 검토했습니다.
  • 실행 오류를 찾고 모듈을 정리하며 테스트 가능한 형태로 다듬었습니다.
활용 결과게임 규칙과 플레이 흐름 구현
02 사운드

ElevenLabs

효과음 제작

공격과 스킬 발동 순간을 더 분명하게 전달할 수 있도록 게임용 효과음을 생성하고 적용했습니다.

  • 기물별 스킬에 어울리는 타격음과 발동음의 방향을 정했습니다.
  • 생성한 사운드를 게임의 효과음 파일로 정리하고 전투 연출과 연결했습니다.
  • 소리의 길이와 재생 타이밍을 반복해서 확인해 행동의 구분을 강화했습니다.
